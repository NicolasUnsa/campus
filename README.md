Descripción del proyecto:
CAMPUS es una plataforma web integral que aloja dos servicios web totalmente independientes y aislados entre sí. El proyecto aborda dos necesidades críticas del entorno universitario dentro de una única infraestructura digital: la gestión bibliotecaria institucional por un lado, y la economía circular de materiales entre estudiantes por el otro.
